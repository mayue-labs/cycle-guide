# cycle-guide

自行车品牌与实用骑行指南：从选车、变速到锻炼、舒适骑行和日常保养的桌面网页。

- GitHub 仓库：[mayue-labs/cycle-guide](https://github.com/mayue-labs/cycle-guide)
- 在线访问：[https://mayue-labs.github.io/cycle-guide/](https://mayue-labs.github.io/cycle-guide/)
- 发布状态：已于 2026-11-18 发布并完成在线页面验证。Pages 从 `main` 分支根目录部署。

## 项目概况

- 原生 HTML、CSS、JavaScript，页面集中在 `index.html`，无构建步骤、无运行时第三方依赖。
- 7 个品牌，补充企业上市状态、股票代码与上市地点；5 张代表车型照片；图片与品牌标识以内嵌数据形式保存，页面离线可用，来源链接需联网访问。
- 8 个章节，左侧悬浮目录、章节定位高亮、车型大图与独立来源弹窗。
- 交互演示可调整前牙盘、后飞轮与踏频，查看理论车速和齿比变化。
- 以桌面 Web 阅读为交付范围。正文最大宽度 1120px，右侧至少预留 80px。
- 数据核对日期为 2026-11-18。机构估算、编辑性预算与健康教育内容均在页面注明范围和来源。

本地直接用现代桌面浏览器打开 `index.html` 即可。需要通过本地地址预览时，可在项目目录执行：

### GitHub Pages 发布方式

当前已配置为从 `main` 分支根目录发布，后续推送该分支会触发更新。需要重新配置时，设置路径：

1. 推送代码，使远端存在 `main` 分支。
2. 打开仓库 **Settings → Pages**。
3. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
4. 分支选择 **main**，目录选择 **/(root)**，保存。
5. 等待部署成功，再打开页首 Pages 地址确认页面和交互。

操作说明：[GitHub 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 交互规则

### 用户视角

- 点击目录跳转章节，滚动时高亮当前章节；系统偏好减少动态效果时关闭平滑滚动。
- 点击车型图查看完整大图；点击关闭按钮、弹窗背景或按 Esc 关闭。
- 点击章节标题右侧“查看来源”，查看该节资料；全局数据说明保留在页首。
- 调整前盘、后齿片或踏频，实时更新齿比、每圈距离和理论车速；极端斜链组合会提示。

### 实现视角

- `updateGearing()`：齿比 = 前齿数 ÷ 后齿数；每圈距离 = 齿比 × 2.10；车速 = 每圈距离 × 踏频 × 60 ÷ 1000。
- `updateToc()`：按章节位置更新 `aria-current="location"`；滚动事件通过 `requestAnimationFrame` 合并处理。
- 来源弹窗从对应 `template` 克隆内容；大图弹窗复用原图数据。
- **初始化脚本位于所有正文、弹窗和模板之后**，保证元素已创建后再绑定事件，避免单个空元素报错中断其他功能。
- 所有交互在本地运行；无后台服务、表单提交或账号体系。

## 修改注意事项

- 优先定位章节 id、CSS 类或函数局部修改，避免重写内嵌大量图片数据的整页。
- 桌面布局参数集中在样式区的目录布局与阅读列调整注释附近；修改宽度时同步检查表格和图片。
- 品牌标识、名称与所在地共用第一列；第二列为企业上市状态、股票代码和上市地点，避免增加列数后挤压正文。上市依据追加在 `#source-brands` 模板；喜德盛保留“未查到上市记录”，不要将其改为已获正式确认的“未上市”。
- 车型图必须保持随列等比缩放，避免恢复为超出单元格的固定宽图片。
- 修改模型齿数、踏频或轮周长时，同步更新演示说明、默认结果、计算逻辑与本 README。
- 调整 DOM 顺序时，保持脚本在所引用的弹窗、模板之后，或明确在 DOM 就绪后初始化。
- 更新健康与保养内容时核对可靠来源；保留必要的症状处理提示，不把通用示例写成个人训练处方。
- Logo 和产品照片的来源及权利归属见页面说明；不要将其误标为项目原创素材。

## 维护与版本交付规则

1. 修改 `index.html` 后同步更新 README 的实际参数和 CHANGELOG 的当日记录。
2. 检查 8 个目录锚点、7 个标识、5 张车型图与来源模板的完整性。
3. 验证齿比控件能更新结果、三类弹窗能打开关闭、目录高亮正常初始化。
4. 检查桌面正文宽度、右侧留白、表格换行和图片适应；不扩大为手机端适配任务。
5. 按本次明确要求，**跟踪包含内嵌图片的 `index.html`**，以保证仓库和 Pages 可完整交付。当前文件约 0.5MB；频繁替换图片会增加 Git 历史体积，避免无关图片重编码。
6. 临时脚本、检查工具依赖、截图和原版备份不进入仓库；提交前检查差异、分支和远端。
7. 推送前再次核对远端状态；发布后更新 Pages 状态，并实际验证在线页面。
